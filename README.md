# Elliptical spring wire length calculator

Live: https://selloriybrendi.github.io/elliptical-spring-calculator/

Wire length for coil springs wound on an elliptical (oval) former: constant pitch, stepped pitch,
progressive pitch and conical taper. The page shows the exact value (Gauss–Legendre quadrature)
beside closed forms based on Ramanujan's second ellipse-perimeter approximation.

Cite: Kenjaev, O. U. (2026). *Arc length of an elliptical helix via Ramanujan's second perimeter
approximation, with explicit pitch thresholds* (Version 2). Zenodo. https://doi.org/10.5281/zenodo.22984129
